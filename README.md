# Rosévin
_Rosévin_ is a tipsy, warm theme for Zed, inspired by PinkCatBoo. It features a color palette that includes rose pink, banana yellow, and lavender, creating a warm and inviting experience. The theme is designed to bring a cozy, playful vibe to your editor, making coding feel a little more delightful.

## Preview
![Rosévin Preview](assets/rosevin.png)

## Install

1. Open Zed.
2. Open the command palette (<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd>) and enter _zed: extensions_.
3. Search for the _Catppuccin_ extension and install.
4. Open the command palette (<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd>) and enter _theme selector: toggle_ in the command palette and select **Rosévin**.
